📖 GETTING STARTED (First Time)
═══════════════════════════════════════════════════════════════════

Step 1: Double-click START_HERE.sh
        (or run: ./START_HERE.sh)

Step 2: Browser opens with search links

Step 3: Click through links to browse properties

Step 4: When you find a property:
        → Copy the URL
        → Note the price
        → Go to tracker (link at bottom)
        → Paste URL + price
        → Click "Add"

═══════════════════════════════════════════════════════════════════
🔄 DAILY/WEEKLY TRACKING
═══════════════════════════════════════════════════════════════════

1. Open: vacation_tracker.html (bookmark it!)

2. Click each property link

3. Check current price on the website

4. If price changed:
   → Enter new price in the box
   → Click "Update Price"

5. Watch the chart for trends!

Then run START_HERE.sh again to regenerate links!

🚨 TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════

Problem: Search links don't open
Solution: Run START_HERE.sh again

Problem: Tracker not saving data
Solution: Use same browser each time, enable cookies

Problem: Can't see prices
Solution: Make sure dates are correct on booking sites

Problem: Links are old
Solution: Edit config.json and run START_HERE.sh
